## 一、最佳上线时间

### 核心结论

```
最佳窗口：2027 年 1 月 14 日（周四）上午 10:00 太平洋时间
```

### 为什么

| 因素 | 数据 |
|------|------|
| 税季爆发 | 1-3 月占税类 App 年收入 **70-80%** |
| 下载峰值 | 1 月 = 1.4× 年平均，12/25 = +22% |
| 算法友好 | 周四 Apple 编辑团队刷新日 |
| 竞品 CPA 低 | 1 月第 2 周 CPA 尚未暴涨（2 月涨 5-10×） |
| W-2 到达 | 1 月中旬雇主开始发 W-2，搜索量飙升 |
| 避开死区 | 12/22-28 Holiday Freeze（审核关闭）、WWDC 周、iPhone 发布日 |

## 二、自然流量方案（$0 预算）

### 2.2 Reddit（安全策略）

```
不推 App，只回答问题。

搜索关键词每天 30 分钟：
  r/freelance + r/tax + r/smallbusiness + r/selfemployed
  → "quarterly tax" "estimated tax" "self employed deductions"
  → "mileage tracking" "home office" "SEP IRA"

回复模板：
  1. 直接回答问题（提供 IRS Pub 编号、计算公式）
  2. 不提到 App
  3. 如果有人私信问 → "I work on a tax app, happy to share"
  4. Profile 放 App Store 链接
```
