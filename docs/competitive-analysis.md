## Competitor Profiles

### 1. Expensify
- **Pricing:** Free (individual, limited) / Collect $5/mo / Control ~$9/mo
- **App Store Rating:** 4.7★
- **Strengths:**
  - Industry leader, brand recognition
  - SmartScan OCR is good
  - Strong QuickBooks/Xero integration
- **Weaknesses:**
  - Built for TEAMS, not solo freelancers
  - "Free" tier is misleading — categorization requires paid plan
  - UI is cluttered with corporate features (approvals, reimbursements, corporate cards)
  - Aggressive upsells for Expensify Card
  - **Freelancer complaint: "Too much bloat, I just want to scan receipts"**
- **Target User:** Mid-size companies with expense approval workflows
- **Our Opportunity:** Same OCR quality, zero bloat, honest pricing

### 2. Foreceipt
- **Pricing:** Free (100 receipts, data deleted after 12 months!) / $5/mo / $12/mo Business
- **App Store Rating:** 4.6★
- **Strengths:**
  - IRS/CRA tax category alignment
  - Clean, simple UI
  - Mobile + web sync
  - Affordable
- **Weaknesses:**
  - **Free tier is a trap** — data auto-deleted after 12 months
  - 200 receipt/month cap on $5 plan
  - Small team, slow feature development
  - Limited AI capabilities (basic OCR, no smart categorization learning)
  - QuickBooks integration only on $12/mo plan
- **Target User:** Budget-conscious freelancer who files own taxes
- **Our Opportunity:** Better AI, no data deletion dark patterns, smarter auto-categorization

### 3. Smart Receipts
- **Pricing:** Free (ad-supported) / Plus ~$2.99/mo / Premium ~$4.99/mo
- **App Store Rating:** 4.7★
- **Strengths:**
  - AI-powered OCR
  - Cross-platform (iOS + Android + Web)
  - PDF/CSV/ZIP export
  - Good App Store presence
- **Weaknesses:**
  - Ad-supported free tier is annoying
  - UI feels dated
  - OCR accuracy inconsistent (user reviews)
  - Category customization limited
  - No smart learning from user corrections
- **Target User:** Any receipt scanner, broad positioning
- **Our Opportunity:** Modern UX, better AI accuracy, learning from user behavior

### 4. SimplyWise
- **Pricing:** Free (50 receipts) / $40/yr ($3.33/mo) / $90/yr with export
- **App Store Rating:** 4.5★
- **Strengths:**
  - All-in-one (receipts + expenses)
  - Tax refund optimization feature
  - Simple interface
- **Weaknesses:**
  - **50 receipt cap on free is tiny**
  - Export locked behind $90/yr plan
  - Small App Store presence
  - Limited AI capabilities
- **Target User:** Casual user, light receipt needs
- **Our Opportunity:** Scale from 50 to 500+ receipts, better AI, more generous free tier

### 5. Wave
- **Pricing:** Free accounting / Receipts add-on $8/mo (US) / Pro $16/mo
- **App Store Rating:** 4.7★ (accounting app)
- **Strengths:**
  - Free core accounting
  - Established brand
  - Integrated invoicing
- **Weaknesses:**
  - Receipt scanning is an **add-on**, not the core experience
  - $8/mo for receipts alone is expensive
  - UI is accounting-first, not receipt-first
  - No AI-powered smart categorization
- **Target User:** Small business owner who also needs accounting
- **Our Opportunity:** Receipt-first experience, half the price, better AI

## Key Market Gap

| What Users Want | What Exists |
|----------------|-------------|
| Super simple — open app, snap, done | Expensify: cluttered with team features |
| AI that learns my categories | Foreceipt: static IRS categories |
| Generous free trial (no data trap) | Foreceipt: deletes data after 12 months |
| Modern, delightful UX | Smart Receipts: dated UI |
| Honest pricing, no dark patterns | SimplyWise: export paywall |
| Receipt-first (not accounting-first) | Wave: receipts are a side feature |

**The Gap = Our Product Position:**
"AI-powered receipt scanner that's fast, simple, and built for freelancers who hate bookkeeping."

---

## Competitive Advantage (Defensibility)

1. **AI learning loop** — The more a user corrects categories, the smarter it gets. Competitors use static categorization.
2. **Receipt-first UX** — Open app = camera ready. Not buried in menus.
3. **Honest freemium** — Generous free tier with clear upgrade path. No data deletion dark patterns.
4. **Tax-season virality** — Built-in "export for CPA" creates word-of-mouth every March-April.
5. **Speed to market** — 6-week build with AI assistance vs competitors' slow release cycles.
